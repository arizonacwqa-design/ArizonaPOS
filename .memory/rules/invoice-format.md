# Invoice Format Rules

## Source
- Thermal: `src/components/ThermalInvoice.jsx`
- A4: `src/components/A4Invoice.jsx`
- PDF: `src/lib/invoicePdf.js`
- QR: `src/components/InvoiceQr.jsx`
- Reprint modal: `src/pages/Reports.jsx` — `ReprintModal` and `SalesTable`
- Share: `src/lib/share.js` → `buildInvoiceWhatsAppMessage()`

## Three Output Formats

### 1. Thermal (80mm)
| Element | Details |
|---------|---------|
| Width | 80mm (CSS) |
| Font | Monospace, small (10px-12px) |
| Hidden DOM | `#thermal-invoice` — `print:block` via CSS |
| Header | Logo (80x80px), company name, address, phone, WhatsApp, Instagram |
| Customer | Name, phone, vehicle, plate |
| Items | Service/item, quantity, amount |
| Inventory | Used items shown (if any) |
| Totals | Subtotal, discount, tax, GRAND TOTAL |
| Payment | Method shown |
| QR Code | Embedded via InvoiceQr component (64px) |
| Footer | "Thank you — {company name}", WhatsApp |

### 2. A4
| Element | Details |
|---------|---------|
| Layout | Full letter/A4, light background |
| Header | Logo, company name, "Detailing · PPF · Tint", invoice number |
| Customer | "Bill To" section with name, phone, vehicle |
| Payment | Method shown |
| Items | Table with headers: Description, Qty, Unit, Amount |
| Totals | Subtotal, discount, tax, GRAND TOTAL |
| Notes | Shown if present |

### 3. PDF (jsPDF)
| Element | Details |
|---------|---------|
| Library | jsPDF + jspdf-autotable |
| Header | Gold-accented header row (RGB: 201, 162, 39) |
| Formats | A4 and Thermal (80mm) |
| Trigger | Download buttons in post-sale actions and reprint modal |

## Invoice Numbering
- Format: `INV-{number}` (e.g., `INV-1001`)
- Sequence: `invoice_number_seq` starts at 1001
- Auto-generated by Postgres `DEFAULT` on `sales.invoice_number`
- UNIQUE constraint on `invoice_number`

## Business Rules
- Thermal print uses CSS class `.print-thermal` on `<body>`
- A4 print uses CSS class `.print-a4` on `<body>`
- Materials (non-revenue items, `!service_id`) are hidden via CSS class `.no-print` in thermal print
- Reprint via Reports page loads items from DB and renders same components
- No invoice editing after creation

## Impacts
- **Business**: Invoice is the official receipt. Thermal is primary (shop floor), A4 for customer copies.
- **Financial**: Totals must match DB exactly — no recalculation on print.
- **Inventory**: No impact. Inventory usage shown for reference only on printed invoice.
